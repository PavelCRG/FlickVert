# Changelog

## 0.1.16

- Made the tools catalog show only operations implemented in FlickVert and removed manual converter installation prompts.
- Added built-in RTF text extraction and kept CSV/TSV, image, PDF, document-text, subtitle, and archive operations local to the app.
- Disabled media, RAW, and other conversions that still required separate programs.

## 0.1.15

- Matched the action wheel editor preview to the quick wheel, including custom colors, transparency, and dark appearance.

## 0.1.14

- Added a personalized action wheel, local photo themes, favorites, conversion history, and reusable image, PDF, video, and audio profiles.
- Added safe batch file renaming, background completion notifications, reusable watermark text, and image-to-PDF page ordering and rotation.
- Added image details and kept the quick menu's custom colors, transparency, and opacity settings.

## 0.1.13

- Added customizable quick-menu colors and opacity controls, including a fully transparent preset, with backup and restore support.
- Kept the conversion format label clear of the file name in the center preview.

## 0.1.11

- Reflowed the base styles into readable rules and made the window usable at smaller sizes.
- Kept file-specific actions gated by compatible selections and preserved keyboard-accessible controls.

## 0.1.10

- Added clear labels to every quick-wheel choice, including tools and file actions.

## 0.1.9

- Added visible output format labels to the conversion wheel.
- Added a clear loading indicator for longer conversions, file actions, and archive operations.

## 0.1.8

- Refined the home page, tools catalog, and settings with clearer spacing, compact icon actions, and subtle transitions.
- Made settings pages use the available width and improved keyboard shortcut visibility on Home.

## 0.1.7

- Fixed Windows modifier tracking so releasing one side of Shift, Ctrl, or Alt does not cancel the other side while it remains held.

## 0.1.6

- Simplified the quick wheel into a clean icon-first layout with accessible action names and format-specific icons.
- Prevented outdated file inspection results from replacing the current selection after a newer drop or closing the popup.

## 0.1.5

- Reshaped Home and the tools catalog around clearer, grouped actions and engine availability.
- Reorganized Settings into focused pages and refined the quick wheel's labels, layout, and update notices.
- Made Windows the active release target; macOS packaging is paused.

## 0.1.4

- Added a consistent orange accent, with existing appearance and custom color preferences preserved.
- Organized home, tools, settings, and app shell styles into separate files and improved compact-window readability.
- Added optional background startup after sign-in while keeping the app available in the system tray.

## 0.1.3

- Refined the sidebar update panel with clearer status, state icons, and a full-width update action.
- Restyled the on-device privacy note and version label to match the app's sidebar cards.

## 0.1.2

- Replaced corrupted text symbols with consistent vector icons in the tools catalog and quick wheel.
- Refined catalog spacing and requirement badges for clearer scanning.

## 0.1.1

- Reworked the workspace and settings navigation, added a searchable tools and formats catalog, and removed the history page.
- Added configurable global shortcuts, drag modifiers, appearance colors, and close-to-tray behavior.
- Improved file path copying, PowerShell folder opening, onboarding, and the Windows installer experience.
- Added product research, specifications, and a roadmap for the unified FlickVert experience.
