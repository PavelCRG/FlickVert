# Changelog

## 0.1.5

- Reshaped Home and the tools catalog around clearer, grouped actions and engine availability.
- Reorganized Settings into focused pages and refined the quick wheel's labels, layout, and update notices.
- Made Windows the active release target; macOS packaging is paused.

## 0.1.4

- Added a consistent orange accent, with existing appearance and custom color preferences preserved.
- Organized home, tools, settings, and app shell styles into separate files and improved compact-window readability.
- Added optional background startup after sign-in while keeping the app available in the system tray.

## 0.1.3

- Refined the sidebar update panel with clearer status, state icons, and a full-width update action.
- Restyled the on-device privacy note and version label to match the app's sidebar cards.

## 0.1.2

- Replaced corrupted text symbols with consistent vector icons in the tools catalog and quick wheel.
- Refined catalog spacing and requirement badges for clearer scanning.

## 0.1.1

- Reworked the workspace and settings navigation, added a searchable tools and formats catalog, and removed the history page.
- Added configurable global shortcuts, drag modifiers, appearance colors, and close-to-tray behavior.
- Improved file path copying, PowerShell folder opening, onboarding, and the Windows installer experience.
- Added product research, specifications, and a roadmap for the unified FlickVert experience.
