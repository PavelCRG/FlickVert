# Круговое меню FlickVert

## Цель

Пока пользователь тащит файл в Проводнике или Finder, короткое нажатие Shift открывает у курсора меню выходных форматов. Отпускание файла над сектором выполняет конвертацию локально и сохраняет новый файл в `Downloads/FlickVert`. Текущее меню по горячей клавише и основной экран приложения сохраняются.

## Решения

- Повторить жест Sweetch: удерживать левую кнопку для перетаскивания и коротко нажать/отпустить Shift. README Sweetch подтверждает именно такой жест; Shift + правая кнопка не используется, поскольку она мешает штатному перемещению файла из Explorer/Finder.
- Меню получает пути из штатного Tauri drag/drop, а глобальный listener только распознаёт жест и указатель.
- В секторах показывать лишь реально доступные выходные форматы для входного файла и установленных движков.
- Изображения конвертировать уже имеющимся Canvas-конвертером; медиа, документы и RAW направлять в существующие Rust команды.
- Оформление системное: системный шрифт и палитра Canvas/AccentColor, компактное полупрозрачное кольцо, FV и имя файла в центре, без постоянной анимации.
- macOS требует разрешения Accessibility/Input Monitoring для глобального наблюдателя ввода; при отсутствии разрешения остаётся текущая клавиатурная команда.
- URL, виртуальные OLE-вложения, архивы, пресеты и скачивание движков сейчас не добавлять.

## План

1. Добавить обработчик глобального жеста Shift во время перемещения левой кнопки, который сообщает приложению позицию указателя; не подавлять ввод пользователя.
2. Научить QuickMenu принимать drag/drop события, отображать доступные форматы кольцом, подсвечивать сектор при наведении и преобразовывать после drop.
3. Добавить минимальный Rust endpoint для безопасного чтения уже выбранного файла и переиспользовать существующие команды конвертации/уникальной записи.
4. Обновить помощь и настройки по жесту и разрешению macOS; сохранить старую клавиатурную команду.
5. Собрать React и Windows release executable, проверить diff, удалить временную копию Sweetch, оставить исследовательскую записку.
