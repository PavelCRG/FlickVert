# FlickVert: план 100 улучшений

**Исходная точка:** приложение версии 0.1.3: Tauri, React и Rust; локальная обработка, системный трей, глобальное сочетание клавиш, радиальное меню, файловые действия, редактор изображений и необязательные движки FFmpeg, Pandoc, ImageMagick, LibreOffice и Poppler.

**Цель:** превратить текущие возможности в цельный и быстрый файловый инструмент: действия легко найти, доступность форматов показана честно, исходные файлы защищены, а фоновые операции и установщики понятны.

**Ограничения продукта:** не загружать файлы в облако, не добавлять аккаунты и скрытую телеметрию, не устанавливать внешние движки без отдельного согласия, не заявлять формат как поддерживаемый до проверки фактической операции. Новые функции сначала должны использовать имеющиеся модули; новые зависимости добавлять только при подтверждённой необходимости.

**Приоритеты:** P0 — надёжность основного опыта; P1 — главные пользовательские функции; P2 — расширения и полировка. Фазы упорядочены по зависимостям; внутри каждой фазы пункты можно делать небольшими независимыми релизами. После каждой фазы — сборка, проверка затронутых сценариев и просмотр diff. Публикация — только после показа списка изменений и отдельного согласия пользователя.

## Контрольные точки

- **После 01–20:** интерфейс и каталог согласованы с фактической матрицей операций; поиск доступен мышью и клавиатурой.
- **После 21–40:** очередь не теряет файлы, длинную работу можно отменить, редактор не меняет оригинал.
- **После 41–60:** медиаконвертации и PDF/документы ограничены теми движками, которые реально доступны.
- **После 61–80:** файловые операции безопасны, а настройки не ломают глобальные сочетания и старые профили.
- **После 81–90:** обработка локальна, временные данные очищаются, производительность и разрешения проверены.
- **После 91–100:** установка, обновление и релиз проверены на всех целевых системах; публикация ожидает отдельного согласия.

## Правило ведения плана

Пункты выполняются короткими релизами. Перед каждым этапом проверяется текущая ветка и незакоммиченные изменения; существующие планы в `docs/superpowers/plans/` остаются самостоятельными. Устаревший пункт заменяется только после проверки, что функция действительно доступна на всех заявленных платформах.
