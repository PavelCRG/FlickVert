# Sweetch: исследование поведения кругового меню

Источник: [krllmrzv/Sweetch](https://github.com/krllmrzv/Sweetch), MIT, изученная версия из локальной временной копии.

## Как работает жест

Пользователь начинает обычное перетаскивание файла левой кнопкой. Пока кнопка удерживается, коротко нажимает и отпускает Shift. Приложение показывает верхнее прозрачное кольцо у курсора, не забирая фокус у исходного окна. Файл продолжает перемещаться; текущий сектор следует за указателем, отпускание запускает выбранную операцию. Escape или отпускание вне меню отменяет выбор. Есть отдельное сочетание клавиш для выбранных в Проводнике файлов.

Реализация Sweetch следит за мышью и клавиатурой низкоуровневыми хуками на отдельном потоке. Контроллер отличает drag-жест от обычного клика, вычисляет доступные операции по расширению и наличию движка, а окно само определяет сектор по позиции перетаскивания. Операции проходят через очередь задач. Сохранение использует уникальный путь, не перезаписывая исходник или предыдущий результат.

Помимо обычных путей, Sweetch умеет получать виртуальные OLE-файлы, изображения буфера обмена и URL. Эти сценарии остаются за рамками текущей доработки FlickVert: локальный конвертер должен прежде всего надёжно обработать файлы из Проводника/Finder.

## Что перенести в FlickVert

- Жест «тащи файл левой кнопкой → нажми Shift → отпусти над форматом».
- Меню у указателя, видимые сектора форматов и центральную информацию о файле.
- Список только тех форматов, которые FlickVert может создать установленными движками.
- Отмену через Escape/отпускание за пределами меню.
- Существующие локальные движки, уникальные имена и папку `Downloads/FlickVert`.

FlickVert остаётся Tauri + React + Rust. Исходный C# код Sweetch не переносится.
