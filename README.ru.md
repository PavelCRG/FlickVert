# FlickVert

Локальный помощник для конвертации файлов в Windows и macOS.

<br clear="left" />
<div align="center">
  <p><a href="README.md">English</a> · <a href="README.zh-CN.md">简体中文</a></p>
</div>

FlickVert помогает работать с файлами прямо из Проводника и Finder. Начните перетаскивать файл и нажмите Shift — рядом с указателем появится круглое меню. Наведите файл на нужный формат или действие и отпустите кнопку мыши. Главная показывает возможности приложения, а настройки разбиты по разделам.

## Скачать и установить

В **Windows 10/11 x64** нажмите ссылку на установщик EXE вверху страницы и откройте скачанный файл. Там же доступны MSI и портативный ZIP. Для портативной версии распакуйте архив и запустите `FlickVert.exe`.

В **macOS 13 или новее** выберите на странице релизов DMG для Apple Silicon или Intel, откройте его и перетащите FlickVert в Applications. macOS может показать предупреждение при первом запуске, так как приложение пока не нотарифицировано.

Windows требует Microsoft Edge WebView2 Runtime. Дополнительные движки конвертации устанавливаются отдельно.

Текущий релиз — `0.1.3`. Установленная версия проверяет подписанные обновления при запуске и каждые шесть часов. Windows Setup распространяется в EXE и MSI; портативную версию нужно обновлять вручную. Для следующего релиза отправьте тег версии, например `v0.1.4`: GitHub Actions соберёт установщики Windows и macOS и опубликует релиз.

## Быстрый старт

1. Запустите FlickVert. При первом запуске откроется краткое руководство, при следующих — главная страница.
2. Начните перетаскивать файл, нажмите **Shift** и наведите его на формат в круговом меню.
3. Готовый файл появится рядом с исходным. Поддерживаемые форматы и настройки доступны в главном окне.

Закрытие главного окна скрывает FlickVert в системный трей. Круговое меню и глобальное сочетание клавиш продолжают работать в фоне. Чтобы полностью завершить FlickVert, выберите **Выход** в меню трея.

Сочетание **Ctrl+Alt+Space** открывает быстрое меню для выбранных в Проводнике или Finder файлов. Чтобы сменить его, откройте **Settings**. В меню можно переключать режимы клавишами **1/2/3**, выбирать пункт стрелками и запускать его клавишей **Enter**. Клавиша **Esc** закрывает меню.

## Круговое меню

1. Начните перетаскивать файл из Проводника или Finder, удерживая кнопку мыши.
2. Нажмите **Shift**, чтобы открыть круг с вариантами конвертации.
3. Для инструментов можно сразу нажать **Ctrl** в Windows или **Command** в macOS; для действий с файлом — **Alt** в Windows или **Control** в macOS. Меню остаётся открытым после отпускания клавиши.
4. Наведите указатель на нужный пункт и отпустите кнопку мыши. Нажмите **Esc**, чтобы отменить действие.

Круг также можно открыть сочетанием клавиш, а затем перетащить файл на нужный пункт.

## Поддерживаемые форматы

| Тип файлов | Возможности | Требования |
| --- | --- | --- |
| Изображения | PNG, JPEG, WebP, BMP, SVG, HEIC, TIFF, AVIF и PDF | Для HEIC, TIFF, AVIF и RAW установите ImageMagick. Обычные изображения и SVG можно конвертировать без внешнего движка. |
| Аудио и видео | Форматы, поддерживаемые FFmpeg | Установите FFmpeg отдельно. Доступны сжатие видео, отключение звука, извлечение аудио, создание миниатюр и обработка звука. |
| Субтитры | SRT, VTT и ASS | Требуется FFmpeg. |
| Текст и электронные книги | Форматы, поддерживаемые Pandoc | Установите Pandoc отдельно. |
| Документы Office | Конвертация в PDF; для некоторых форматов — в изображения | Требуется LibreOffice; для PNG/JPEG также нужен Poppler. |
| Таблицы и презентации | XLSX, ODS, CSV; PPT/PPTX/ODP в PDF, PNG или JPEG | Требуются LibreOffice и, для вывода изображений, Poppler. |
| PDF | PNG, JPEG, TXT, Markdown; DOCX и EPUB через Pandoc | Требуется Poppler. Страницы изображений сохраняются в отдельную папку в разрешении 300 DPI. Извлечение текста не сохраняет исходную вёрстку. |
| Архивы | Создание и безопасное распаковывание ZIP | Архив сохраняется рядом с выбранными файлами. Небезопасные пути и ссылки отклоняются. |

Инструменты изображения позволяют менять размер, поворачивать и отражать картинку, переводить её в оттенки серого, обрезать, сжимать и удалять метаданные. До 100 изображений можно объединить в PDF. Редактор также поддерживает кадрирование, закрашивание области, подписи, фон, яркость и контраст; результат сохраняется новым PNG рядом с оригиналом.

**Пока не поддерживаются:** OCR сканов PDF, преобразование PDF в PAGES/PPTX/XLSX, TAR/GZIP/RAR, интерактивная обрезка и объединение аудио или видео.

## Куда сохраняются файлы

По умолчанию результат сохраняется рядом с исходным файлом. В **Settings → Output settings** можно выбрать другую папку; вариант **Save beside original** возвращает сохранение рядом с оригиналом.

FlickVert не перезаписывает существующие файлы. Если имя занято, к новому имени добавится номер, например photo (2).webp.

## Сборка из исходного кода

Карта интерфейса, системного кода и сборки находится в [описании структуры проекта](docs/architecture.md).

Установите Node.js 24, стабильный Rust и системные зависимости [Tauri](https://v2.tauri.app/start/prerequisites/), затем выполните:

    npm ci
    npm run dev

Поддерживаются Windows 10/11 и macOS 13 или новее. В macOS для работы меню перетаскивания предоставьте FlickVert доступ к функциям Accessibility и Input Monitoring.

## Конфиденциальность

Файлы обрабатываются на устройстве: FlickVert не отправляет их и не использует аналитику. Установленная версия обращается к GitHub Releases для проверки и загрузки подписанных обновлений. Дополнительные движки конвертации — отдельные программы, которые запускаются локально.
