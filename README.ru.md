FlickVert работает рядом с Проводником и Finder. Перетащите файл, нажмите Shift и отпустите его на действии в круговом меню. Большое окно служит стартовым экраном с историей и настройками.

## Быстрый старт

1. Запустите FlickVert. Сначала откроется стартовый экран; после его закрытия FlickVert останется в трее, пока вы работаете в Проводнике или Finder.
2. Перетащите файл, нажмите **Shift** и отпустите его на нужном формате в меню возле указателя.
3. Готовый файл появится рядом с оригиналом. Стартовый экран, история и настройки открываются через трей.

## Закрытие приложения

После закрытия главного окна FlickVert остаётся в трее. Команда **Show FlickVert** открывает окно снова, а **Quit** завершает приложение.

Сочетание по умолчанию — **Ctrl+Alt+Space**. Оно открывает быстрое меню и настраивается в разделе **Settings**. Перетащите файл на круг, переключайте режимы клавишами **1/2/3**, выбирайте сектор стрелками и запускайте его клавишей **Enter**. **Esc** закрывает меню. Само сочетание не считывает выделенный файл в Проводнике или Finder.

Во время перетаскивания нажмите **Ctrl** (Windows) или **Command** (macOS), чтобы открыть инструменты, либо **Alt/Option**, чтобы открыть действия с файлом. Для изображений доступны изменение размера, поворот, отражение, чёрно-белый режим, квадратная обрезка, сжатие и объединение до 100 изображений в PDF. С установленным FFmpeg также доступны сжатие видео, отключение звука, извлечение аудио, миниатюра, сжатие и нормализация громкости аудио. Можно создать ZIP-архив или безопасно распаковать его в новую папку. Меню действий позволяет копировать и перемещать выбранные файлы и папки в `Загрузки/FlickVert`, показать объект в Проводнике/Finder, скопировать путь или открыть папку объекта в терминале.

## Круговое меню перетаскивания

1. Начните перетаскивать файл из Проводника или Finder, удерживая левую кнопку мыши.
2. Не отпуская кнопку мыши, нажмите **Shift**. Круговое меню появится возле указателя; после этого Shift можно отпустить.
3. Наведите указатель на формат и отпустите кнопку мыши. Нажмите **Esc**, чтобы отменить действие.

Для этого жеста нужно начать перетаскивание файла из Проводника или Finder. Круг можно также открыть глобальным сочетанием клавиш и затем перетащить на него файл.

## Поддерживаемые форматы

| Файлы | Форматы | Примечания |
| --- | --- | --- |
| Изображения | PNG, JPEG, WebP, GIF, BMP, HEIC, TIFF, AVIF, SVG, RAW | PNG/JPEG/WebP встроены. HEIC, TIFF, AVIF, SVG и RAW требуют ImageMagick. |
| Аудио и видео | Зависит от FFmpeg | FFmpeg устанавливается отдельно. |
| Субтитры | SRT, VTT, ASS | FFmpeg конвертирует между этими форматами. |
| Текстовые документы и электронные книги | Зависит от Pandoc | Pandoc устанавливается отдельно. |
| Документы Office в PDF | Зависит от LibreOffice | LibreOffice устанавливается отдельно. |
| RAW-фотографии | Зависит от ImageMagick | ImageMagick устанавливается отдельно. |
| Архивы | Создание и распаковка ZIP | Сохранение рядом с выбранным файлом; небезопасные пути и ссылки блокируются. |

## Куда сохраняются файлы

- Файлы из Проводника и Finder сохраняются рядом с оригиналами.
- FlickVert не заменяет существующие файлы: если имя занято, добавляется номер, например `photo (2).webp`.

## Сборка из исходного кода

Установите Node.js 24, стабильную версию Rust и [системные зависимости Tauri](https://v2.tauri.app/start/prerequisites/). Затем выполните:

```sh
npm ci
npm run dev
```

Поддерживаются Windows 10/11 и macOS 13 или новее. В macOS разрешите FlickVert доступ к разделам «Универсальный доступ» и «Мониторинг ввода», чтобы использовать круговое меню с Shift. Для быстрого меню также доступно заданное сочетание клавиш.

## Конфиденциальность

Файлы обрабатываются на устройстве и никуда не отправляются. Дополнительные движки конвертации также работают локально.
